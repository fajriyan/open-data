# Open Data Indonesia

Kumpulan data publik Indonesia yang bisa digunakan secara bebas. Data diorganisir dalam folder terstruktur:

- **`data-nasional/`** — data yang mencakup seluruh Indonesia
- **`data-kota/`** — data spesifik per kota
- **file di root** — referensi umum (jurnal, IPTV, API, dll.)
